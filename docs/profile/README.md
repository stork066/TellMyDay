# Sam — synthetic About-Me profile

> **EVERYTHING in this folder is synthetic and fictional.** No real person is described. The profile exists to give Foundry IQ enough context to ground a demo narration with citations. There are no real names, organizations, addresses, employers, schools, or care-setting details anywhere in this profile or in the app demo.

## Persona summary

- **Sam** — a 29-year-old adult who uses an AAC app to share moments from their day.
- Lives at home with a parent and a younger sister.
- Has a small, consistent set of people, places, and routines that matter to them.

The five files in this folder map to the five symbol categories in the app:

- `people.md` — friends and family Sam talks about.
- `places.md` — places Sam goes regularly.
- `activities.md` — what Sam likes to do.
- `food.md` — food and drink preferences.
- `comfort.md` — what comforts Sam, what upsets them, and what helps.

Each file is intentionally short and factual so the agentic retrieval pipeline produces clean, specific citations.
