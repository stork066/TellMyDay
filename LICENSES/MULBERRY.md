# Mulberry Symbol Set attribution

The picture symbols in `public/symbols/` are from the **Mulberry Symbol Set**, a communication symbol set designed for adults with language difficulties.

- GitHub: https://github.com/mulberrysymbols/mulberry-symbols

## What CC BY-SA 4.0 requires

- **Attribution.** Give credit to the original authors. We do this in this file and in the project README.
- **ShareAlike.** Derivative works of the symbols must be released under the same CC BY-SA 4.0 license. The Tell My Day application code (MIT) is *not* a derivative of the symbol set — the symbols are used as separate assets shipped alongside the app. Any modified symbols in this repository, if added later, must remain under CC BY-SA 4.0.

The original Mulberry Symbol Set is the work of Garry Paxton and Paxtoncrafts Charitable Trust. The current set is maintained by the Mulberry Symbols project. See the upstream repository for the full list of contributors.
